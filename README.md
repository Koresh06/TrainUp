# Trainer Bot

Telegram-бот для записи на тренировки, оформления заявок на программы тренировок
и консультации с тренером. MVP разрабатывается под одного тренера, архитектура
сразу закладывает возможность подключения других тренеров в будущем (по подписке).

## Статус

🚧 В разработке. Сейчас — этап проектирования доменной модели и репозиториев.

## Стек

- Python, aiogram + aiogram_dialog
- PostgreSQL + SQLAlchemy + Alembic
- Redis (FSM-хранилище)
- taskiq (фоновые задачи и напоминания по расписанию)

## Архитектура

Чистая архитектура, слои:

- `domain` — сущности и бизнес-правила, без зависимостей от БД/telegram
- `application` — use case'ы, оркестрируют domain через интерфейсы репозиториев
- `infrastructure` — SQLAlchemy, Redis, taskiq, DI, реализации репозиториев
- `presentation` — aiogram/aiogram_dialog
